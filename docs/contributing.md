# contributing

thanks for wanting to help! heres how.

## ways to contribute

### add lyrics
biggest help. check the [library](/library) for songs with gray dots - those need lyrics. see [adding-lyrics.md](./adding-lyrics.md) for details.

### fix translations
spot an error? have a better interpretation? open an issue or pr. translations are subjective so explain your reasoning.

### report bugs
found something broken? open an issue with:
- what you expected
- what actually happened
- browser/device if relevant

### suggest features
have an idea? open an issue. were keeping it minimal but open to good suggestions.

## code contributions

1. fork the repo
2. create a branch (`git checkout -b fix/something`)
3. make your changes
4. run `pnpm typecheck`
5. commit with a clear message
6. open a pr

## style guide

- keep it minimal - no over-engineering
- typescript everywhere
- no unnecessary dependencies
- match existing code style
- test locally before submitting

## commit messages

keep em short and descriptive:
```
add lyrics for utopia
fix search dropdown on mobile
update discography docs
```

no need for conventional commits or anything fancy.

## questions?

open an issue. were friendly, promise.
